# AWS architecture icons

These unmodified SVG assets come from the official [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) package dated July 31, 2026. AWS provides them for architecture diagrams and related materials; see that page for usage guidance.

Local filenames identify the services: Amazon Cognito, Amazon Bedrock AgentCore, Amazon Bedrock, Amazon CloudWatch, Amazon VPC, Amazon S3, AWS CodeBuild, Amazon ECR, and AWS PrivateLink. Each corresponds to the package’s `Arch_<service>_64.svg` asset.

The diagram embeds the icons so the SVG is self-contained. The AgentCore service icon represents Runtime, Gateway, Identity, and the managed consent portal; component labels distinguish their roles. The PrivateLink icon represents interface endpoints; the adjacent text also identifies the separate S3 gateway endpoint.
